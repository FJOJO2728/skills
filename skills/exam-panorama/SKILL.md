# 考试全景工作流（exam-panorama）

为任意考试生成一份《X考试全景_内容形式与答题办法.md》：联网核验考情，只讲考试本体，不做备考规划。

## 触发与产出

- **触发**：用户明确表示某考试已锁定要考（"确定考X""报了X""X锁定了"），或直接索要「X考试全景」「X笔试全景」。
- **产出**：`考情\<考试系统>\<考试名>笔试全景_内容形式与答题办法.md`（目录可自定，按考试系统与地区分文件夹）。多环节考试（含面试/实操）叫「考试全景」，纯笔试叫「笔试全景」。

## 四条铁律

1. **只讲考试本体**：题型、题量、时间、赋分、流程、常规答法。备考规划、排期、选岗/报考决策属于用户自己的事，一律不做。
2. **分层标注口径**：无标记＝官方原文；〔机构〕＝机构统计/经验口径；〔预测〕＝官方未公布、按参照系推测。官方未公布项（单题分值、精确题量等）必须写"官方未公布"，不得虚构精确数字。
3. **官方文件优先**：先找官方公告/大纲/问答（官网，或用户库内PDF——考情目录下常存有大纲/公告PDF，用 pdftotext 抽取）。机构文章只做交叉验证与题型统计。网搜摘要质量差时（年份混装、来源含糊）果断弃用，改走官方PDF。
4. **覆盖更正不删旧档**：库里旧考情文档数据过时的，在新全景里标注"旧文档XX部分以本文为准"，不改动旧文件。

## 七节模板

1. **头部meta**：编制时间｜依据（官方文件名+发布日期）｜**适用口径（用户锁定的卷别/类别/科目/语言）**｜定位声明（只讲考试本体）｜口径标记图例｜⚠️动态项提示（以官方公告/准考证为准）。
2. **一、考试是什么**：流程定位一句话 + **时间轴表**（官方节点写实日、未定节点标"预计"）+ 规模感（招录数/报名数/竞争比）。
3. **二、科目与卷别**：科目表（时长/满分/题型属性）+ **与国考笔试的结构性差异明列**（凡是机制不同的地方——当日时序、合格线机制、计分规则、模块构成——都要单独点名）+ 卷别/类别机制。非公职考试此节改为"考试机制要点"（评分标准、机考/纸笔、重考政策等）。
4. **三、四、各模块题型拆解与常规答法**：每模块卡＝**考什么 / 常规答法 / 认知**三段；**题量口径框**置于模块总表之前（官方公布与机构统计分开）；模块表后附"时间总账与作答顺序"。与国考方法论同构的部分明说"全额复用《国考笔试全景》第X节"，只展开差异。
5. **五、分数设置与赋值机制**：成绩合成公式｜单题分值公布与否｜分数线（合格线≠进面线要分清）｜面试/后续环节形式与权重｜**关键认知5条左右**（战略含义层，不是个人规划）。
6. **六、报考基本面（名词卡表）**：身份/年龄/资格/地点/流程术语，一行一条。
7. **七、与库里既有文档的衔接**：逐个指名（国考笔试全景、申论备考体系、行测备考手册、各省选调分析、旧全景地图等），说明哪些通用、哪些以本文为准。

尾注：事实来源清单（官方文件+机构来源，注明口径）。

## 答法写作规范

- 常规答法＝考场方法论（排除法、代入、公式、结构模板），不是个性化建议。
- 表格优先；关键数字加粗；每模块末尾"认知"一句收束定位。
- 语言类/技能类考试（雅思、教资、计算机等级、驾照科目等）：七节骨架不变，"模块"换成考试部分（听说读写/科目一~四），"答法"换成官方评分标准解读＋题型策略，"赋分机制"节讲算分方式（如雅思四科均分、教资报告分120制折算）。

## 交付与收尾

- 文件直存考情目录；聊天只给 computer:// 链接＋一句定位，**不写长摘要**（用户偏好：直接给文件）。
- 若同一考试考情有更新（新公告/新大纲），在原全景文件上修订并更新编制时间，不另开新文件。
