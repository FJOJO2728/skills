HTML 不直接开写：先按预设池遴选 2-3 个候选风格（联网搜真实参考站），出文字方案请用户拍板（推荐放第一），选定后才产出；说「看样张」则先出并排对比页。

全链定位（创意产线第①段「定风格」）
选定风格后输出的「风格规格单」是产图 / 产页 / 产片共用输入；海报 / 卡片 / 视频包装同样先过本池再执行（产图 shengtu / mono-color / guizang-social-card，产片 guizang-product-video）。
分工：本 skill 管选型与规格；页面执行与动效实现交给技能库里对应的前端/动效技能（如 design-taste-frontend、emil-design-eng、animate 等），没有就自行按规格实现；规格单未定，下游不许动。

工作流
用户提出 HTML 制作需求（或海报 / 卡片 / 视频包装的定风格需求）→ 判断内容类型（随笔 / 笔记 / 文化 / 古文 / 纪实 / 资讯……）。
从「预设风格池」挑 2-3 个最契合的候选。
联网搜参考站：为每个候选搜 1-2 个高质量真实网站作为风格参考（见「参考站搜索」；3D/WebGL 类先查「参考站沉淀」）。
出文字方案，用 AskUserQuestion 呈现，用户回 A/B/1/2 即选定：
每个候选含：气质一句 + 配色 + 字体 + 布局一句 + 适用场景 + 产图线一句 + 参考站（站名＋链接＋一句「参考什么」）。
推荐项放第一，标注「推荐」。
用户选定 → 直接产出完整 HTML（单文件、内联 CSS，遵守所选风格的全部规格），同时输出风格规格单（供产图 / 产片段取用）。
用户回「看样张」→ 先生成一个对比页：同一段样例内容分别渲染为全部候选风格，供并排比较；选定后再出正页。
用户回「换一批」→ 从池中另选候选，重出方案。

讲解页 / 教学页（页型配方，2026-10-04）
触发：把一个概念 / 知识点做成「打开就学、能动手玩」的页面（学某算法、弄懂某机制、Karpathy 式换形式的 HTML 档）。
风格：照常走本工作流遴选，推荐候选——学习向＝康奈尔笔记风，技术向＝终端代码风，信息向＝瑞士国际主义风，原理分解＝包豪斯风；用户明说不用选风格时从其言。
功能硬要求（缺一不可）：①开篇一句话结论；②一张核心示意图；③一个可操作的小实验（滑块 / 下一步按钮），操作后图示与解释同步更新；④重置按钮；⑤单文件、CSS / JS 内联、无外部依赖、适配手机。
分寸：知识正确 ＞ 交互可用 ＞ 视觉装饰。

参考站搜索
时机：挑出候选后、出方案前；每候选 1-2 个，全程 ≤5 个。
来源优先：设计集锦站（awwwards、Godly、Land-book、Siteinspire、Httpster、Minimal Gallery、Typewolf、Brutalist Websites、Fonts In Use）＞ 知名工作室 / 获奖案例 / 产品官网；WebSearch 按「内容类型＋风格关键词＋集锦站」检索。
标准：真实上线、水准高、贴合候选与内容类型；宁缺毋滥。呈现：站名＋链接＋一句「参考什么」。
搜不到就如实说，不硬凑；只作方向对照，绝不复制其内容或品牌元素。

参考站沉淀（3D/WebGL 类优先取用，现搜可补充）
- Lusion（lusion.co）——3D×编辑排版分层；软质感打光
- Bruno Simon（bruno-simon.com）——「可把玩」交互的度
- Igloo Inc（igloo.inc）——叙事性 3D 首屏；单色克制
- Refik Anadol（refikanadol.com）——粒子 / 数据美学的克制用法
回填：现搜验证过的优质站按类目补进本行，注明日期与「参考什么」。

全链禁则（taste 系硬规则，对 18 个风格与所有产出生效）
serif 纪律：默认劝退衬线大标题；品牌血统确属 editorial / 古典 / 文化类（如新中式、古籍、装饰艺术、美国往事、东方美学海报）可用，但须在方案中写明理由。
Lila Rule：禁 AI 味紫色渐变（紫罗兰→蓝紫低对比渐变）；蒸汽波、星图占卜两风格的紫 / 深蓝渐变是风格本体，属注册在案的例外。
强调色锁死：全页强调色按条目执行、不得再加；条目本就多色的（孟菲斯撞色、包豪斯三原色）按条目为限。
italic 下伸部：斜体行 leading ≥ 1.1，防止 g/j/y 被裁切。
z-index 克制：层级 ≤ 5，弹层之外禁止 z-index 军备竞赛。
噪点 / 纹理层：一律 pointer-events: none，不得挡交互。
每条都可在具体项目 override，但必须像例外条目那样写明理由，不接受「感觉好看」。

预设风格池（18 个，八维规格＝六维＋产图线；禁则走「全链禁则」，例外注册在各条产图线内）
1. 极简纸感风
气质：留白至上，安静、克制、呼吸感
配色：暖纸白底 #FAF7F0，墨灰字 #333333，强调色单一克制（赤陶 #C75B39，或纯黑白）
字体：标题 Noto Serif SC 600，正文 Noto Serif SC，大字号，行距 1.8+
布局：单栏，内容区最大宽约 680px，段落间距大
动效：无，或仅 0.3s 淡入；无阴影、无圆角卡片
适用：个人随笔、诗歌、短文、阅读笔记
产图线：适用面＝页面＋海报＋卡片；配方＝mono-color（暖纸白单墨最正）或 shengtu（大留白＋单点赤陶）

动效：无，静态纸面感
适用：学习笔记、会议纪要、知识卡片、复习资料

配色：奶油白底 #FDF4E3（或纯白），纯黑 #000000 描边与文字，主色选一高饱和整块用（黄 #FFDC58、蓝 #84A7FF、红 #FF6B6B、绿 #7BE380 任选其一）；可做 duotone 两色配置（主色 × 底色）；禁用渐变与柔光
字体：超粗无衬线标题（Archivo Black / Space Grotesk 800–900），正文清晰无衬线（IBM Plex Sans / 系统）；标题可全大写＋宽字距
布局：卡片 / 按钮 / 徽标一律 2px 纯黑描边＋4px 4px 0 硬阴影（无模糊、零至极小圆角）；粗边框网格与整块色块分区，元素错落压叠
动效：悬停或按下时元素向阴影方向平移 4px 且阴影消失（像把贴纸按进桌面），松开复原；干脆利落无花哨缓动；可用粗笔触星星 / 箭头 / 锯齿作装饰
适用：工具页、个人主页、作品集、活动 / 发布会页、年轻化品牌页
产图线：适用面＝页面＋卡片＋视频包装；配方＝guizang-social-card（年轻化硬阴影卡）＋shengtu 贴纸感
18. 东方美学海报（转译自同名生图提示词，2026-10-09 入池）
气质：策展式东方编辑美学 —— 留白、裁切、一条与主体相系的视觉线索；纸感＋克制文字，忌堆传统符号
配色：暖象牙纸底 #FAF6ED，墨黑 #1C1A17，深棕 / 灰棕 #6B5D4F，古铜金 #A68A56；深朱砂 #A83A2B 仅当原图有色彩线索时点睛，无则不用
字体：中文主标题宋体衬线（Noto Serif SC）大字距，可竖排，全页唯一抢眼文字；英文小题＋档案标签（VISUAL ARCHIVE · NO. 001）小号落于底边或页缘
布局：单一视觉焦点偏置（底 / 侧 / 贴边），主体可破框延展；大面积留白与疏密强对比；一块主文本＋一角微型信息块，不均匀分布、不填满留白
动效：无，或仅 0.35s 淡入；禁强渐变、光效、做旧脏渍
适用：文化展览、随笔诗歌、作品集的海报与页面；文字须回应画面具体内容，禁口号与长段落
产图线：适用面＝页面＋海报＋卡片；配方＝shengtu「东方美学海报」提示词原样取用（serif 例外理由：东方编辑美学的宋体衬线是风格本体，见全链禁则第 1 条）
