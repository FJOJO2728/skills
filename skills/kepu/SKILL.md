# 科普小文改写

把“材料”变成“短文”的一套硬规矩。执行者拿到材料后，按本文件从头做到尾，产出即定稿。

## 一、什么时候启用

用户给来一批学习材料，并说“改成科普小文”“讲透”“供学习记忆”“不要有做题痕迹”“写得像科普”之类的话。

材料本身是**试题＋解析**只是最常见的一种形态。不管来源是试题、课件、讲义、笔记、政策文件、行业报告还是论文摘要，本技能的产出都不是“讲解”，而是一篇篇能独立阅读的短文。

与 ganhuo 的分工：要一篇能从头读到尾的短文→本技能；要点状罗列的知识干货→ganhuo。拿不准用户要哪种，先问一句。

## 二、第一原则：讲知识，不讲题

拿到材料先剥壳：**只留里面的知识，把“题”这层皮整个去掉。**

判断标准一句话：改完以后，一个从没见过原材料的人读，完全读得懂、读得有用，而且**读不出这原本是一道题**。

三条硬线：

1. **不出现试卷元素**——题号、题干、选项（A/B/C/D、甲乙丙丁）、“本题”“文段”“材料中”。
2. **不出现判题语言**——“正确／错误”“排除／当选”“符合文意”“表述有误”“故选”。
3. **不出现应试标签**——考点、易错点、高频、真题、命题、得分点。

辨析性内容**要保留、不许丢**：材料里考两个词的区别，改写时就把这两个词各自指什么讲清楚，读者读到界线自然分得开。区别在于呈现方式——是“词义科普”，不是“甲对乙错”。

## 三、文风五条

**准确**：专业术语照用，但第一次出现时当场用一句白话化开。数字、年份、机构名、术语名写全写对，宁可少写，不可写错。

**晓畅**：一句话只装一个意思。长句拆开，主动语态优先，不绕弯、不套娃。

**有趣**：靠**具体**，不靠形容词。生活里的一个例子、能想象出来的一个画面、反差够大的一个数字——这三样比写十个“十分有趣”管用。

**有判断**：结论直接说。“它解决的是……”好过“它在某种程度上可能有助于……”。

**克制**：不堆修辞、不喊口号、不用感叹号收尾。趣味来自内容本身，不来自卖弄。

## 四、怎么切篇

**一篇只讲一件事。** 检验方法：能用一句话说出这篇在讲什么，且这句话里**只有一个主语**。

**该合并的**：几份材料讲同一主题、同一原理、同一段脉络（例如“新质生产力”与“建成科技强国”同属科技创新的国家布局）——合成一篇，合并后仍然只有一个主语。合并**只认实质关联**：共同主题、共同机制或同一条脉络；不为整体感强行拼接，结尾也不加牵强的主题总结（用户长期偏好，优先遵守）。

**不该合并的**：只是“都出自同一份卷子”这种形式相似、实质各讲各的——**分开写，不硬凑**。宁可十篇短，不凑一篇长。

**排列**：按主题聚类排序（如 理论政策 → 科技 → 文艺 → 自然），由执行者判断，**不按材料原顺序**，也不要留下任何“第 1、2、3 题”的顺序痕迹。

## 五、每一篇怎么写

- **标题**：具体、有信息量、可独立成立。写“一滴燃料的脾气”“山水画不是照相”，不写“关于燃油的思考”“材料一解析”。
- **开头**：直接从现象、疑问或一个具体场景切入。不写“众所周知”“随着社会的发展”。
- **主体四问**：**是什么**（定义与边界）→ **从哪来**（来源与沿革）→ **怎么运作**（机制、原理、措施）→ **到哪为止**（限度、争议、适用条件）。四问不必全写，但**讲到“限度”这一步才算讲透**。
- **收尾**：给一个能带走的判断或一个能记住的画面。不写“综上所述”“让我们记住”。
- **长度**：单篇 **250–600 字**；合并篇不超过 **900 字**。讲完即止。

## 六、事实纪律

1. **以材料为准，但不照抄错误**。年份、数字、名称先核一遍；发现明显笔误或事实错误，按正确的写，并**另附一行说明改了什么**（例：某材料把“10 号柴油”与“凝点 ≤ -10℃”混写，改写时按标准写法处理并在交付说明里点出）。
2. **不确定的不写**。拿不准的数字、年份、人名、引文，宁可不写也不猜。材料没给、你想补的背景，只补有把握的。
3. **引文给出处**；转述不必。
4. **术语第一次出现给全称**，有通用原文或缩写的括注一次。

## 七、禁止清单（写完全文搜一遍）

| 禁止出现 | 类别 |
|---|---|
| 题号、题干、A/B/C/D、“本题”“文段”“材料中” | 试卷元素 |
| “正确／错误”“排除”“当选”“符合文意”“故选” | 判题语言 |
| “考点”“易错点”“高频”“真题”“命题” | 应试标签 |
| “综上所述”“让我们记住”“由此可见”（收尾式） | 套话 |
| **顺口溜、口诀、“记法：……”、藏头、打油诗** | **一律不用（用户明令，最高优先级）** |
| ①②③式的解析罗列 | 除材料本身即步骤性内容外，一律写成连续段落 |

## 八、交付（三条长期偏好，优先遵守）

- **对话直接交付**：用户没有要求文件时，直接在对话里输出全文；用户需要可保存的稿件时，再存 md——一级标题 + 每篇一个 `##` 小标题，篇与篇空行分隔。
- **不另列关键词**：正文不加“关键词”栏，标题直接进入正文，文首文末都不加。
- **来源零标注**：正文里不保留任何来源标注（不写“改写自第 10 题”）。用户明确要对照表时，才在文末另起一节“材料索引”，用最简形式。

交付后附三行以内的说明：写了几篇、哪几篇做了合并、改了材料里的哪处错（如有）。

## 九、交付前自查（逐条过，任一条不过就改）

- [ ] 搜“题干、题号、本题、文段、故选、当选、正确／错误、考点、易错点、真题、表述有误、符合文意”零命中？选项样式（A．／（A）／甲、乙）零命中？
- [ ] 每篇都能用一句话说出“它讲的是什么”，且只有一个主语？
- [ ] 没有口诀、顺口溜、“记法”？
- [ ] 每篇都写到了“限度／边界”？
- [ ] 数字、年份、专名核对过一遍？
- [ ] 通读一遍——像人写的科普，还是像解析的改写？
- [ ] 长度达标（单篇 ≤600 字／合并篇 ≤900 字）？

## 十、样例（三篇，覆盖三种典型材料）

### 样例 A｜材料：一组关于“新质生产力”的选择题（干扰项把“高质量”写成“高速度”）

## 生产力也会换档

经济增长有两种完全不同的来源。一种是把同样的东西做得更多：多投人力、多烧煤、多占地；另一种是同样的投入产出更多——靠技术换代、靠要素重新组合、靠产业整体升级。前一种有天花板，后一种才是长期出路。政策语言里高频出现的新质生产力，说的就是后一种。

它由技术革命性突破、生产要素创新性配置、产业深度转型升级催生，具有高科技、高效能、高质量的特征，基本内涵是劳动者、劳动资料、劳动对象及其优化组合的跃升，核心标志是全要素生产率大幅提升。一句话概括：特点是创新，关键在质优，本质是先进生产力。

其中“高质量”三个字值得停一下。它说的不是跑得更快，而是质地变了——同样的投入，产出不一样了。所以判断一件事是不是新质生产力，看的不是它有多新、投了多少钱，而是它有没有让全要素生产率真正抬起来。

### 样例 B｜材料：一段填空材料，考“机遇／身临其境”（干扰词：设身处地、感同身受、抚今追昔）

## 屏幕里的博物馆，为什么反而更“在场”

网上博物馆把展柜搬进了屏幕：不必买票、不必赶路，半夜也能把一件文物看到底。这一步解决的是“到得了”的问题。但“看到”和“在场”是两回事——真正的难题是让人走进那个场景里去，而多媒体情景展示做的正是这件事：光线、声音、叙事一起作用，观众被放回当年，站在事情发生的位置上。

汉语里有一串词都在描述“进入别人的处境”，分工却不同。“设身处地”是替别人着想，落点在体谅；“感同身受”偏于感激与共鸣；“抚今追昔”是站在眼前的景物前回想往事，人还留在今天；只有“身临其境”说的是脚真的踩进了那个环境。技术给革命文物带来的，恰恰是最后这一种机会——它把“隔着玻璃看”变成“走进现场看”。

### 样例 C｜材料：一道关于燃油的科技常识题（选项涉及热值、抗震剂、辛烷值、柴油标号）

## 一滴燃料的脾气

汽油、柴油、航空煤油都是从石油里切出来的，脾气却完全不同，标号的意思也完全不是一回事。

先说一个常被误解的：**标号越高的汽油，不是越干净、也不是越有劲。**92、95、98 这些数字量的只有一个东西——辛烷值，也就是抗爆震的能力。汽油在气缸里被压缩后必须由火花塞点燃；压得太狠，它会自己先烧起来，这就是爆震。辛烷值越高，越扛得住高压。所以标号是给发动机用的，不是给油品分等级的。

柴油的标号走另一套逻辑：它量的是**凝点**，也就是这种油在低温下开始凝固、不再流动的温度。0 号柴油凝点不高于 0℃，-10 号、-20 号、-35 号依次往下走。标号越低，能扛的冬天越冷——北方一入冬就得换油，就是这个道理。凝点和密度没有关系。

还有两个冷知识。乙醇汽油并不比普通汽油耐烧：乙醇的热值约 26–27 兆焦/千克，汽油约 44–46 兆焦/千克，差了一大截，它的长处是环保和可再生。而航空煤油从不加含铅抗震剂——铅会污染环境、损坏发动机，它的抗爆性靠调配烃类成分来实现。天上飞的东西，容不下将就。
