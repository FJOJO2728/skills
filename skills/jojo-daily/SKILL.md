# 资讯处理流水线（jojo-daily / InfoDigest）

用户发来资讯链接或文章文件时：读取、消化、提炼，生成精简 Markdown 笔记。适用于：微信公众号文章链接（mp.weixin.qq.com）、AI 日报条目、英文博客链接、上传的 .md 文件。

## 抓取通道

1. **微信文章**：页面大（约 1MB）。先试 web_fetch（结果可能落到持久化输出文件，需从该文件读取）；标题取 `<h1 class="rich_media_title">`，正文取 `<div id="js_content">`（删 script/style 块，`</p>`、`<br>`、`</section>`、`</h\d>` 换行，去其余标签，html.unescape，压空白）。**若抓取失败（风控页、Redirect cancelled 等），不反复重试**：换用其他抓取工具或请用户直接贴正文／给转载源，如实说明。
2. **其他网页**：正常抓取，提取标题与正文（article 标签优先）；B站视频走官方 API：`api.bilibili.com/x/web-interface/view?bvid=`（标题/简介/时长/统计）＋ `x/v2/reply?type=1&oid={aid}&sort=2`（热评）。
3. **已上传 .md**：直接读取处理。

## 笔记结构（目标：3 分钟读完）

### 1. 总结主体

- 一段话概述文章核心论点和事实
- 开头括注「（媒体名/作者，**处理当天日期**）」如「（机器之心，2026-09-22）」——是处理日不是发布日；**禁止出现「来源：」字样**
- 英文文章用中文总结，标题括注中文译题

### 2. 要点信息

- 3–6 条，每条 1–2 句；只留关键数据、发现、结论、机制
- 重点用 ==高亮==（Obsidian 兼容），关键术语/数据用 **加粗**
- 中文语境内全角标点（URL、代码、markdown 标记保持半角）

### 3. 即刻抓手（实用主义四问：用·抄·造·赚）

- **用（直接调用）**：资讯里能直接上手的东西——产品入口、开源库、API、数据集、文档、白皮书、免费额度。写「名称＋入口＋门槛（免费/付费/需申请）」。合格线：放下手机前就能打开它
- **抄（模仿迭代）**：别人已跑通、值得先抄再改的套路——工作流、提示词、评测口径、组织方法、运营打法。写「照抄什么＋我改成什么」。合格线：能写出「照抄 A、改成 B」这一句
- **造（激励创造）**：能点火的东西——反常识观点、没人满足的需求、技术拐点、可复用母题。写「火种＋我可以做一个什么」，当天记下念头（页面/工具/文章/实验）。合格线：落成具体造物念头
- **赚（投资变现）**：**默认必答**——「人赚不到认知以外的钱」，这一问的任务就是打开认知：认识＝机制、思路＝路径、格局＝量级、脑洞＝非常规角度。写两样：①**赚钱逻辑**——钱从谁流向谁、为什么流（谁在付费，买的什么：注意力/情绪/信息差/省时/身份）；②**投产比**——要投入什么（钱/时间/技能/风险）、能撬动什么量级的产出、一句判定值不值。允许脑洞角度（套利、错位、搭便车、卖水人）。唯一过滤＝违法犯罪，不装清高、不嫌钱小。合格线：说得出谁付钱给谁、值不值得下场

- **有货才写与默认必答**：用·抄·造凑不出就整条省略，不硬凑，不要每篇都套同样的框架；**赚默认必答**——先找钱的角度再决定写不写，确实无角度才明写无感（应趋罕见）
- **允许第一人称**：四问内可以用「我」；但仍从资讯内容出发，资讯里没有的个人信号不硬扯
- 每问至多 1 条；用·抄·造各 1–2 句，赚可至 2–3 句（逻辑＋投产比），具体到「做什么、怎么做」

### 4. 专名全罗列（笔记最后）

- 提取文中所有重要专名，全罗列不遗漏
- 按类型分组，每类一行，组内顿号分隔，不加解释；无则省略该类
- 分类：模型/产品、机构/公司、人物、地点、平台/工具、概念/术语

## 存档规范

- 存入你的笔记目录（如 `./inbox/`，可自定）；**文件名＝文章原标题**（保持原文语言）
- Windows 非法字符处理：`"`→全角“”；`:`→全角：或去掉；`|`→全角｜或去掉；**`/` 必须替换成 - 或删除**（否则会把文件拆进子目录）
- 文件内容格式：

```
{原文URL}

### {文章标题}

（媒体名，2026-09-22）{总结主体}

**要点信息：**

- ...

**即刻抓手（用·抄·造·赚）：**

1. **用：** ...
2. **抄：** ...
3. **造：** ...
4. **赚：** ...

**专名全罗列：**

- **模型/产品：** ...
- **机构/公司：** ...
- **人物：** ...
- **地点：** ...
- **平台/工具：** ...
- **概念/术语：** ...
```

## 注意事项

- 每篇独立成文件，不合并不建索引；多链接逐篇处理
- 无法抓取时如实告知，不编造内容
- 若你在维护一个信息归档站或索引，处理完可同步更新索引（本技能不限定存储位置，按你的工作流接上即可）
