# 行测速解库（xingce）

本文件自足，全部规则内联，不依赖外部文件。方法体系整理自花生十三公开教学（截位直除、415 份数、假设分配、ABRX 均为公考培训通用方法），示例数据全部自编。

## 0. 使用纪律（最高优先级）

1. **默认输出三段**（刷题模式）：**速解**（考场最快路径，1–3 行）→ **答案** → **考点/易错**（1–2 行）。不复述题干，不写鼓励语，不写备考建议。
2. 用户说"细讲 / 讲原理 / 学一下 / 慢点讲"→ 切换完整解析：题型识别 → 思路 → 完整计算 → 易错点 → 同类拓展。
3. 涉及数字的题**先自己验算再作答**；发现题目数据矛盾、选项有误或无解，直说并给依据，不硬凑答案。
4. 备考规划、刷题量安排不由本 skill 主动输出；用户给出自己的计划时只做配合执行。
5. 申论批改、评分、范文类需求转交 shenlun；本 skill 只在用户明确要求时给题型框架，不临时编造数据。
6. 用户要练习题时，按指定模块自编含解析题组，数据自编。

## 1. 考场总策略

以国考副省级卷（130 题 / 120 分钟，数量关系 10 题）为基准。题量变化时按性价比重排，**资料分析永远先做**。

| 顺序 | 模块 | 题量 | 用时 | 跳题阈值 | 目标正确率 |
|---|---|---|---|---|---|
| 1 | 常识判断 | 20 | 8 min | 30 s | 55%+ |
| 2 | 资料分析 | 20 | 25 min | 90 s | 90%+ |
| 3 | 判断推理 | 40 | 33 min | 60 s | 80%+ |
| 4 | 言语理解 | 40 | 33 min | 60 s | 75%+ |
| 5 | 数量关系 | 10 | 8 min | 120 s | 做 4–5 + 蒙 |

- 依据：资料分析分值密度最高、技巧性最强，头脑最清醒时做；常识不会就是不会，不纠结；数量最后选做加蒙。
- **涂卡**：每模块做完立即涂，不留到最后。
- 数量分工：8 分钟内挑 3–5 道稳拿题型，每题不超过 90 秒，剩余统一蒙（单题期望 0.25 分，见 §3.4）。
- 超过跳题阈值的题立即标记跳过，收尾回来处理或蒙。

## 2. 资料分析（主战场）

### 2.1 ABRX 互推（母公式）

恒等主线：X = A − B，A = B(1+R)，R = X/B。

| 已知 | 求 | 公式 | 速算路径 |
|---|---|---|---|
| 现期 A，R | 基期 B | B = A/(1+R) | 截位直除 |
| 现期 A，R | 增量 X | X = A·R/(1+R) | 415 份数 |
| 现期 A，增量 X | 基期 B | B = A − X | 直减 |
| 现期 A，增量 X | R | R = X/(A−X) | 截位直除 |
| 基期 B，R | 现期 A / 增量 X | A = B(1+R)，X = B·R | 直接乘 |
| 现期 A，基期 B | R | R = (A−B)/B | 截位直除 |

### 2.2 速算决策树

先看问题和选项，再回材料定位数据，然后：

```
求基期（现期+R）      → 截位直除 A/(1+R)
求增量（现期+R）      → 415 份数：R=1/n → X = A/(n+1)
求增量（基期+R）      → 直接 B×R
求现期（基期+R）      → 直接 B×(1+R)
求 R（现期+增量）     → X/(A−X)
比较增长率            → 比较现期/基期（同对现基时）或 X/基期
比较增长量            → "大大则大"；一大一小比 A·R/(1+R)
比较分数/比重         → 截位商首位 → 化同 → 中间值 → 差分
混合增速              → 居中，偏基期大的一侧；精确用十字交叉
```

### 2.3 截位直除

- 步骤：看选项差距 → 定截位位数 → 分母四舍五入 → 直除，商与选项对齐。
- 位数：选项首位不同 → 截 2 位；首位同第二位不同 → 截 3 位；前两位同 → 截 4 位或改用差分/直算。
- 精度判据：截 2 位的相对误差约 ≤ 5%/首位数字（首位 1 ≈ 5%，首位 9 ≈ 0.5%）。要求误差小于选项间隔的一半；**分母首位是 1 或 2 时至少截 3 位**。
- 误差方向：分母入大 → 商偏小；分母舍小 → 商偏大。两个相邻选项二选一时，按方向定向选。
- 分子：选项差距大时可同截；分子小于分母的 1/10 时保留分子精度不截。

### 2.4 415 份数法

原理：R = 1/n 时，基期:增量:现期 = n:1:(n+1)，故 **增量 = 现期/(n+1)**，基期 = 现期×n/(n+1)。n 可为分数。

| R | 增量 | R | 增量 |
|---|---|---|---|
| 50%（1/2） | 现期/3 | 10%（1/10） | 现期/11 |
| 33.3%（1/3） | 现期/4 | 9.1%（1/11） | 现期/12 |
| 25%（1/4） | 现期/5 | 8.3%（1/12） | 现期/13 |
| 20%（1/5） | 现期/6 | 7.7%（1/13） | 现期/14 |
| 16.7%（1/6） | 现期/7 | 7.1%（1/14） | 现期/15 |
| 14.3%（1/7） | 现期/8 | 6.7%（1/15） | 现期/16 |
| 12.5%（1/8） | 现期/9 | 6.25%（1/16） | 现期/17 |
| 11.1%（1/9） | 现期/10 | 5%（1/20） | 现期/21 |

- R 非整：就近转化并按偏差方向修正（如 34% 略大于 1/3 → 增量略大于 A/4）。
- 负增长：R = −1/n → 增量 = −现期/(n−1)。
- 特殊比：R = 66.7%（2/3）→ 现期/2.5；R = 150%（3/2）→ 现期×0.6。

### 2.5 假设分配法（口径唯一）

用途：需要同时给出基期与增量，或 R 不规整、直除不便时。

三步：X₀ = 现期×R（偏大）→ X = X₀/(1+R)（修正后为精确值）→ 基期 = 现期 − X。验算：X/基期 ≈ R 则对。

注意：已知基期求现期只是 B×(1+R) 直接乘，不是本法。

### 2.6 特殊分数转化

| 分数 | 1/2 | 1/3 | 1/4 | 1/5 | 1/6 | 1/7 | 1/8 | 1/9 | 1/11 | 1/12 | 1/13 | 1/14 | 1/15 | 1/16 |
|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|
| % | 50 | 33.3 | 25 | 20 | 16.7 | 14.3 | 12.5 | 11.1 | 9.1 | 8.3 | 7.7 | 7.1 | 6.7 | 6.25 |

用法：增长率接近某分数 → 直接换算乘除；分数比较 → 以它们为中间值锚点。

### 2.7 混合增长率与十字交叉

- 两部分混合（整体增速、进出口、城乡、上下半年等）：混合增速居中，**偏基期大的一侧**。
- 十字交叉：量₁:量₂ = (r−r₂):(r₁−r)，r 为混合值。
- 同法适用于浓度混合、平均数混合、比重混合。

### 2.8 题型公式卡

| 题型 | 公式/规则 |
|---|---|
| 现期比重 | 部分/整体 |
| 基期比重 | 现期比重 × (1+R整体)/(1+R部分) |
| 比重升降 | R部分 > R整体 → 上升；< → 下降；= → 不变 |
| 比重差 | 现期比重 × (R部分−R整体)/(1+R部分)，单位**百分点** |
| 现期平均数 | 总量/份数 |
| 基期平均数 | 现期平均数 × (1+R分母)/(1+R分子) |
| 平均数增长率 | (R分子−R分母)/(1+R分母)；升降看 R分子 vs R分母 |
| 是/多几倍 | A/B；A/B−1（差 1） |
| 基期倍数 | 现期倍数 × (1+R分母)/(1+R分子) |
| 年均增长率 | (1+r)^n = 末期/初期；n = 年份差。五年规划叙述（如"十三五"）基期取规划期前一年，n=5；材料只给首末年数值则 n=年份数差 |
| 年均速算 | 1.1^5≈1.61，1.15^5≈2.01，1.2^5≈2.49；1.1^3=1.331，1.2^3=1.728，1.3^3≈2.20 |
| 拉动增长率 | 部分增量/整体基期 |
| 贡献率 | 部分增量/整体增量；拉动 = 贡献率 × 整体R |
| 顺逆差 | 顺差 = 出口−进口（出口>进口） |

### 2.9 比较类秒杀

- 增长量比较：现期大且 R 大 → 增量必大（大大则大）；一大一小 → 比 A·R/(1+R)，R 都不大（≤10%）时直接比 A×R。
- 增长率比较：化为同口径比 A/B 或 X/B。
- 分数比较四板斧：首位/量级 → 化同法（分子分母同倍放大）→ 中间值（1/3、1/2 等锚点）→ **差分法**：比较 a/b 与 c/d（a>c，b>d），看差分数 (a−c)/(b−d) 与小分数 c/d，差分大则 a/b 大。

### 2.10 综合分析（每篇最后一题）

- 从**计算量小的选项**验起：比重/倍数/增速比较 < 基期计算 < 多步计算。
- "约、左右"多为估算可判；"超过、不足、不低于"是 >、<、≥，需按精度算；"均、都、仅、唯一"类绝对化表述常错。
- 时间陷阱："1–3 月"vs"3 月"，累计 vs 当月；单位：万/亿、%/‰。
- 找到一个符合的立即收手，不验证其余。

### 2.11 易错清单

| 陷阱 | 规则 |
|---|---|
| 时间定位 | 划出题干时间词，对照材料表头 |
| 单位 | 万/亿、万吨/亿吨、%/‰，看表头 |
| 量 vs 率 | "增长 X"（量）vs"增长 X%"（率） |
| 同比 vs 环比 | 同比看上年同期，环比看上期 |
| 百分点 vs % | 比重差、增速差是百分点 |
| 是/多几倍 | 多几倍 = 是几倍 − 1 |
| 负增长 | 1+R 变 1−\|R\|，别乘成 1+R |

## 3. 数量关系（10 题：选做 + 蒙）

### 3.1 做蒙分工

第一遍 60 秒/题扫全卷：稳拿题型当场做（和差倍比、工程、利润、容斥、年龄、简单几何、溶液），难的标记跳过。收尾剩余统一蒙。

### 3.2 十二题型速查

| 题型 | 核心方法 |
|---|---|
| 工程 | 赋总量 = 各时间最小公倍数；效率比给比例 → 赋比；人数型赋单人效率 1；交替施工找周期 |
| 行程 | s=vt；两端出发第 n 次相遇路程和 = (2n−1)S；同点环形第 n 次相遇路程差 = n 圈长；追及 = 路程差/速度差；流水 v顺=v船+v水，v逆=v船−v水，v船=(顺+逆)/2，v水=(顺−逆)/2；等距平均速度 2v₁v₂/(v₁+v₂)；比例：s 定则 v∝1/t |
| 利润 | 赋成本 100；利润率 = 利润/成本；售价 = 成本(1+利润率)；折扣 = 现售价/原售价；复合变化 (1±a)(1±b)−1；先涨 a% 再降 a% → 净降 a²（小数，如涨 20% 降 20% → −4%） |
| 容斥 | 二集合：总 = A+B−AB+都不；三集合：总 = A+B+C−两两和+三集交；含"恰两项"时：A+B+C = 恰1 + 2×恰2 + 3×恰3 |
| 排列组合 | 分类加、分步乘；相邻捆绑，不相邻插空；n 个相同球分 m 人：非空 C(n−1,m−1)，允许空 C(n+m−1,m−1)；定序消序（除以定序数）；环列 (n−1)!；错排 0,1,2,9,44 |
| 概率 | 古典 P=满足/全部；"至少"→ 1−反面；独立连乘；抽签不论先后等概率；条件 P(AB)/P(B)；"恰有一个"分类求和 |
| 最值 | 最不利：保证 n 个相同 → (n−1)×种类数+1；和定求最大 → 其余最小化（互异用最小连续自然数组）；和定积最大 → 各相等 |
| 年龄 | 差恒定；设今年列表；"x 年前是 y 倍"→ 那年小的年龄 = 差/(y−1) |
| 几何 | 三角形：两边和>第三边>两边差；相似：面积=比²，体积=比³；周长定，圆>正方>一般矩形；内角和 (n−2)×180°；柱 V=Sh，锥=Sh/3，球 V=4πr³/3 |
| 溶液 | 蒸发/加水溶质不变；混合用十字交叉（同 §2.7） |
| 牛吃草 | 设每牛日食 1：y=(N−x)T；两组条件消元求 x（日长草量），再答问 |
| 鸡兔同笼 | 假设全 A → 差÷(腿差) = B 数；答对得分答错扣分同构 |

### 3.3 整除与代入排除（真数学，优先用）

- 判定：3/9 → 数字和；4/25 → 末两位；8/125 → 末三位；11 → 奇偶位数字和之差为 0 或 11 的倍数。
- 题干出现"平均、每、倍、比、分"→ 答案常具整除性，先排除不满足整除的选项。
- 奇偶：奇±奇=偶；乘法有偶必偶——可排除一半选项。
- 代入排除：优先代好算的选项（整百、中位）；含百分数、年龄的方程优先代入验证。
- 问"至少/最少"→ 从选项最小端向上验证，并对照逻辑下界。

### 3.4 蒙题的真相

- 均匀随机蒙：单题期望 = 0.25×单题分值。做对 4 题 + 蒙 6 题 ≈ 5.5/10（按实际分值折算）。
- 选项分布反推仅在已确认答案分布显著偏离 25% 时有微弱优势，平时不赌。
- 可用逻辑（非玄学）：问"至少"→ 答案不低于逻辑下界；问"最大"→ 排除违反约束的选项；整除性排除优先。

## 4. 言语理解

### 4.1 逻辑填空

- 先找**对应关系**定空格含义：转折（但/然而/却）→ 前后相反；递进（甚至/更）→ 前轻后重；并列（和/与/同时）→ 同向同义；解释（即/冒号）→ 后文释义。
- 再辨词义：语素差异法（比较不同语素，如"遏制-控制/遏止-停止"）；程度轻重按语境。
- 搭配秒杀：激发活力、释放潜力、夯实基础、筑牢防线、厚植优势、破解难题、凝聚共识、彰显品格——搭配不当的选项先排除。
- 顺序：排除搭配不当/程度不符 → 再辩近义。

### 4.2 中心理解

- 三把尺：**主题词**（文段高频核心词，正确答案必含）、**关联词**（转折后是重点、因果看结果、对策重要）、**行文脉络**（总-分看首句，分-总看尾句）。
- 排除：无中生有、偷换概念、范围扩大/缩小、表述绝对化。
- 问题类文段优选对策项，对策无中生有则选问题本身。

### 4.3 细节判断

常见错误六型逐一比对：偷换时间、偷换范围（扩大/缩小/混同）、偷换程度（可能→必然）、偷换因果（强加/倒置）、无中生有、绝对化表述。问"符合"用排除法，问"不符合/正确"逐项对照原文。

### 4.4 语句排序与填空

- 排序：定首句（定义/背景/引入可做首句；指代词、关联词后件、总结词不做首句）→ 抓捆绑（代词-名词、话题一致、时间/逻辑顺序）→ 验证读通。
- 填空：位置定功能——开头总起（话题+观点），中间承上启下（衔接前后话题），结尾总结升华；所填句子话题必须与上下文一致。

## 5. 判断推理

### 5.1 图形推理

规律优先级链（必背）：**元素相同 → 位置（平移/旋转/翻转/遍历）；相似 → 样式（叠加/求同求异/黑白叠加）；不同 → 数量（点线角面素）；数量无 → 属性（对称/曲直/封闭）**。

- 数量优先级：点（交点/切点）→ 线（直线/曲线/一笔画）→ 角（直角数）→ 面（封闭区域）→ 素（种类/部分数）；常考等差、对称、恒定、运算数列。
- 一笔画：奇点数 = 0 或 2 可一笔画（奇点 = 引出奇数条线的点）；多笔画 = 奇点数/2。
- 对称：看轴的方向与数量、轴与图形元素的关系；既是轴对称又是中心对称的常考（如矩形、圆）。
- 黑白叠加规则现场由题干前两图推。
- 立体折纸盒：相对面（相间排列或 Z 字两端）不能同时出现 → 先排相对面；再用时针法/公共边定相邻顺序。
- 截面与三视图：正方体截面三角/四边/五边/六边形；圆柱圆/矩形/椭圆；圆锥三角/椭圆。

### 5.2 定义判断

拆要素比对：主体、客体、方式、目的、原因、结果、条件。多定义题只看被问的那个定义；"属于/不属于"看清；主体或客体不符的直接排除；优先核对最容易验证的要素。

### 5.3 类比推理

- 关系清单：全同（西红柿=番茄）、并列（矛盾：生-死；反对：黑-白）、包容（种属：苹果-水果；组成：轮胎-汽车——**用"是"造句成立为种属，不成立为组成**）、交叉、对应（原材料-成品、职能、场所、因果、顺承）、语义（近义/反义/象征）、语法（主谓宾结构一致）。
- 秒杀：造句法保词序；一级关系选不出 → 二级辨析（感情色彩、程度、具体/抽象、必然/或然）。

### 5.4 逻辑判断

**翻译推理公式**：

| 自然语言 | 翻译 |
|---|---|
| 如果 A 则 B | A→B，逆否 ¬B→¬A |
| 只有 A 才 B | B→A |
| 除非 A 否则 B | ¬A→B（等价 A 或 B） |
| A 是 B 的基础/前提/必要条件 | B→A |
| A 或 B | ¬A→B（否一推一） |
| 德摩根 | ¬(A且B)=¬A或¬B；¬(A或B)=¬A且¬B |
| 递推 | A→B，B→C ⇒ A→C |

**真假推理**：矛盾对（必一真一假）：所有是 ↔ 有些非；所有非 ↔ 有些是；A→B ↔ A且¬B；必然P ↔ 可能非P。解题：找矛盾定真假 → 推其余。反对关系：所有是与所有非必有一假（上反对）；有些是与有些非必有一真（下反对）。

**论证（加强削弱）**：拆结构——论据 →（论证）→ 论点。削弱力度：**否定论点 > 拆桥（断开论据与论点的联系）> 另有他因 > 否定论据**。加强：搭桥、补必要条件、例证。前提型用否定代入法验证（否定该选项结论不成立即为前提）。对照实验类：另有他因削弱、排除他因加强。

**日常结论**：优选弱化表述（可能、有的、部分），排除绝对化（所有、一定、必须、唯一）；无中生有不选；严格限定在文段范围内。

## 6. 常识判断

- 节奏：每题 20–30 秒，不会立即蒙，不回头。
- 三个排误方向：绝对化表述（都、全部、唯一、彻底）多为错；时间对不上（年代、朝代、会议届次）排除；张冠李戴（人物-成就-朝代对应）优先核对。
- 时政靠日常积累（用户有自建时政日报管线），本 skill 不做临时时政科普。

## 7. 申论（框架，批改转 shenlun）

- 审题四要素：作答对象、范围、字数、身份与格式要求。
- 找点：负面词找问题（不足/缺乏/滞后/薄弱），因果词找原因，动词找对策（建立/完善/推进/加强），高频词即重点；每段首末句精读。
- 加工：同义合并，规范词前置作总括，要点序号化；按字数预算分配每点字数。
- 公文：标题（关于+事由+文种）、称谓、正文（开场-主体-结尾）、落款，按题干要求取舍。
- 大作文：总论点 = 题干关键词 + 材料核心观点；结构五段三分；分论点对仗；论证 = 例证 + 理证 + 对比。
- 申论部分转交 shenlun，不在本 skill 展开。
