# 干货提取（ganhuo）

把“材料”变成“分点干货”的一套硬规矩。执行者拿到材料后，按本文件从头做到尾，每一点都是可以直接拿走的知识。

## 一、什么时候启用

用户给来材料，并说“给干货”“提炼干货”“知识点罗列”“把这份材料的干货拎出来”“要能背的要点”之类的话。

与 kepu 的分工：要一篇能从头读到尾的短文→kepu；要一份能扫、能背的点→本技能。拿不准就问一句。材料形态不限（试题与解析、课件、讲义、笔记、政策文件、报告、论文摘要），先剥壳再提点。

## 二、第一原则：讲知识，不讲题

拿到材料先剥壳，**只留里面的知识，把“题”这层皮整个去掉**。三条硬线：

1. **不出现试卷元素**——题号、题干、选项（A/B/C/D、甲乙丙丁）、“本题”“文段”“材料中”。
2. **不出现判题语言**——“正确／错误”“排除／当选”“符合文意”“故选”。
3. **不出现应试标签**——考点、易错点、高频、真题、命题、得分点。

辨析性内容**要保留、不许丢**：材料考两个词的区别，就把界线本身写成干货点——是知识界线，不是“甲对乙错”。

## 三、输出格式（本技能的核心）

- **分点罗列**：Markdown 列表，一行一点。每点是**一个完整的句子**，不写词组、不写“术语：解释”式的标题行。
- **一句打包若干知识点**：一句里塞进 2–5 个相关知识点，用逗号、分号、破折号串成一个意群。**密度是本技能的第一追求。** 同一段材料对照看：

  > 不合格（拆成了三句）：
  > 柴油有标号。标号看凝点。标号越低越耐冻。

  > 合格（一句打包）：
  > 柴油标号量的是凝点，也就是低温下开始凝固、不再流动的温度——0 号柴油到 0℃ 就凝，-35 号能扛零下 35 度的冬天，标号越低越耐冻，但凝点跟密度没有关系。

- **主题分组**：材料跨多个主题时，按主题加小节标题分组（聚类逻辑同 kepu 的“怎么切篇”——只认实质关联，不按材料原顺序，不留“第 1、2、3 题”痕迹）；单主题直接列点。
- **每点自检**：读完这一句能带走一个知识单元，而且能向第三个人复述出来。
- **点完即止**：不设“关键词”栏，不写“综上所述”式总结。

## 四、文风五条（与 kepu 同源，语言风格保持一致）

**准确**：专业术语照用，第一次出现时当场用一句白话化开。数字、年份、机构名、术语名写全写对，宁可少写，不可写错。

**晓畅**：一句一个意群，不绕弯、不套娃。点里可以有分号，但读起来必须一口气跟得上。

**有趣**：靠**具体**，不靠形容词。一个例子、一个画面、一个反差够大的数字——比写十个“十分有趣”管用。

**有判断**：结论直接说。“它解决的是……”好过“它在某种程度上可能有助于……”。

**克制**：不堆修辞、不喊口号、不用感叹号收尾。趣味来自知识本身，不来自卖弄。

## 五、“好记”的门槛

每句至少有一个**抓手**：一个数字、一组对比、一个画面、一处反差——读完能复述给别人。复述不出来，就重写这一点。

“好记”不靠口诀。**口诀、顺口溜明令禁止（最高优先级）**；好记靠的是密度和具体，一个塞满事实的句子本身就比三条口诀好背。

## 六、事实纪律

1. **以材料为准，但不照抄错误**。年份、数字、名称先核一遍；发现明显笔误或事实错误，按正确的写，并**另附一行说明改了什么**。
2. **不确定的不写**。拿不准的数字、年份、人名、引文，宁可不写也不猜；材料没给、你想补的背景，只补有把握的。
3. **引文给出处**；转述不必。
4. **术语第一次出现给全称**，有通用原文或缩写的括注一次。

## 七、禁止清单（写完全文搜一遍）

| 禁止出现 | 类别 |
|---|---|
| 题号、题干、A/B/C/D、“本题”“文段”“材料中” | 试卷元素 |
| “正确／错误”“排除”“当选”“符合文意”“故选” | 判题语言 |
| “考点”“易错点”“高频”“真题”“命题” | 应试标签 |
| **顺口溜、口诀、“记法：……”、藏头、打油诗** | **一律不用（用户明令，最高优先级）** |
| “综上所述”“由此可见”式收尾、“关键词”栏 | 套话与附加栏 |
| 碎词组点（“术语：解释”标题行、三词短语点） | 不是完整句子，不合格 |
| 逐题顺序痕迹（“第 1 题的干货”之类） | 来源痕迹 |

## 八、交付

- 用户没有要求文件时，**直接在对话里交付点列**；用户需要可保存的稿件时，再存 md——一级标题 + 按主题 `##` 分组，点为 `-` 列表。
- **正文不保留任何来源标注**。用户明确要对照表时，才在文末另起一节“材料索引”，用最简形式。
- 交付后附两行以内的说明：提了几组几点、改了材料里的哪处错（如有）。

## 九、交付前自查（逐条过，任一条不过就改）

- [ ] 搜“题干、题号、本题、文段、故选、当选、正确／错误、考点、易错点、真题”零命中？选项样式（A．／（A）／甲、乙）零命中？
- [ ] 每点都是完整句子？每句打包 2 个以上知识点？
- [ ] 每句都有抓手（数字／对比／画面／反差），能复述？
- [ ] 没有口诀、顺口溜、“记法”？
- [ ] 数字、年份、专名核对过一遍？
- [ ] 跨主题的按主题分组、没按材料原顺序？

## 十、样例（材料与 kepu 样例 C 同源，可对照看“成文 vs 点列”）

材料：一道关于燃油的科技常识题（选项涉及热值、抗震剂、辛烷值、柴油标号）

- 汽油标号量的只有辛烷值，也就是抗爆震的能力：92、95、98 越高越扛得住气缸压缩，它是给发动机的压缩比定的档，不是给油品分好坏——加高标号不会让车更有劲。
- 柴油标号走另一套逻辑，量的是凝点，即低温下开始凝固、不再流动的温度：0 号柴油到 0℃ 就凝，-10 号、-20 号、-35 号依次更耐冻，标号越低能扛的冬天越冷，北方一入冬就得换油——凝点和密度没有关系。
- 乙醇汽油并不比普通汽油耐烧：乙醇热值约 26–27 兆焦/千克，汽油约 44–46 兆焦/千克，差了一大截，它的长处是环保和可再生，不是续航。
- 航空煤油从不加含铅抗震剂，抗爆性靠调配烃类成分实现：铅会污染环境、还会损坏发动机——天上飞的东西，容不下将就。
